Student Management System

A beginner-friendly Java project that collects and displays student details.

Features

- Enter student name
- Enter roll number
- Enter marks
- Display student details

Technologies Used

- Java
- Java Scanner class

How to Run

1. Install Java JDK.
2. Open "StudentManagementSystem.java" in VS Code.
3. Compile the program:
   "javac StudentManagementSystem.java"
4. Run the program:
   "java StudentManagementSystem"

Project Status

Beginner project — future improvements may include storing multiple student records and adding search functionality.
